Décision 1 · point de départ

Quand on clique sur « Nouveau », que demande le Studio ?

Le même moteur canonique se trouve derrière les trois propositions. Ici, nous choisissons seulement le langage et l’ordre dans lequel l’utilisateur découvre les possibilités.

◎ Principe no-code : Terrain, chemin et forêt décrivent l’usage dans la carte. Simple, Edge, Corner, Blob ou Mixed décrivent ensuite le modèle de raccords — ils ne doivent pas être un prérequis pour commencer.

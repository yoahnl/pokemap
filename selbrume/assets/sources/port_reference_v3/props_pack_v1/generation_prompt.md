# Prompt ImageGen — props manquants du Port

Use case: stylized-concept
Asset type: 2D RPG pixel-art harbor prop sprite sheet for a 32 px tile grid
Input images: Image 1 is the Port des Brisants map and scale/style reference;
Image 2 is the exact existing prop rendering reference.
Primary request: create exactly five new standalone harbor props, arranged as
five isolated sprites in a strict 3-column by 2-row sheet with the bottom-right
slot empty.

Subjects, one per slot in reading order:

1. a small green weathered barrel partly wrapped in a blue fishing net and rope;
2. a low heap of blue fishing net and tan rope lying on the ground;
3. a round wooden fishing-gear bucket holding a short gaff, coiled rope and a few small tools;
4. a small wooden notice board illustrated only with two silver fish, without letters or text;
5. a small wooden barrel planter with compact green leaves and a few tiny coastal flowers.

Style/medium: polished classic top-down 2D RPG pixel art, three-quarter
orthographic view, crisp hand-pixelled edges, with the same warm wood,
navy-blue net, outline contrast, lighting direction and detail density as the
existing Port props.
Composition/framing: each sprite fully visible, centered in its own equal grid
slot, generous empty padding, no overlap, consistent scale with 32 px map
tiles.
Scene/backdrop: perfectly flat solid `#ff00ff` chroma-key background.
Constraints: exactly five props; no buildings, boats, docks, terrain, water,
characters, creatures, text, labels, grid lines, frames or extra loose objects;
uniform background without shadows, gradients or texture; no `#ff00ff` in any
prop; crisp silhouettes; no cast shadows; no watermark.
